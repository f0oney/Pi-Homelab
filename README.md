# Raspberry Pi Homelab

This project hosts publicly shareable configs and Docker Compose files that have been used in my current Raspberry Pi 4 Homelab. This Homelab hosts the following services:

* 🔧 Pihole - Network wide AD/Domain blocking, Local DNS
* 🔧 Unbound DNS - Private Recursive DNS
* 🔧 Vaultwarden - Hosted Bitwarden Password Manager
* 🔧 Nginx - Reverse Proxy for Local Domains
* 🔧 PiVPN - Using Wireguard to securely connect to my local network
* 🔧 RClone - Data Backups to Cloud Services

As you can see, these config files are arranged in their seperate folders.
