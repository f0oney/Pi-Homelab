With the self-signed certificates created, we can use these to create our HTTPS connections to the local domains. For this example, we will use our Pihole server block we setup previously, to add on HTTPS capability.

----------------------------------------------

Navigate to the server block created earlier via `sudo nano ~/raspberrypi-homelab/nginx/serverblock.conf`, and add the additional lines:

```bash
server {
    listen 443 ssl; # https port
    listen [::]:443; # used for ipv6
    server_name example.com  www.example.com;

    ssl_certificate /etc/openssl/certificates/user.crt; # locations of the certs
    ssl_certificate_key /etc/openssl/keys/user.key; # ocation of the keys

   location / {

       proxy_pass http://pihole:80;  # Backend server URL/port
       proxy_set_header Host $host;
       proxy_set_header X-Real-IP $remote_addr;
       proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       proxy_set_header X-Forwarded-Proto $scheme;
   }
}
```

`ssl_certificate` and `ssl_certificate_key` lines are added, so that the certificate crt and key are obtained and used in it's connection.

`listen 443 ssl` is used in replacement of port 80, as this is the https port.

`listen [::]:80` is used for ipv6 connections.

To redirect http requests to https, we can add the following server block on top:

```bash
server {
    listen 80; # http port
    listen [::]:80; # used for ipv6

    server_name example.com www.example.com;
    return 301 https://example.com/admin;
}
```

With the Pihole server block now complete, we can check for syntax errors, before applying the changes:

```bash
docker compose nginx_proxy nginx -t
docker compose nginx -s reload
```
