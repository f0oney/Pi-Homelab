### Adding the `.md` files

The `.md` files are called from the `docs` folder inside `/home/user/PiProject-homelab/mkdocks/mkdocs-data/`. We can either create `.md` files from scratch, or create and transfer them over into the folder. 

I have created my `.md` files via an note taking application called Obsidian, and transferred these over. These were copied over using the SSH application MobaXTerm, by simply dragging them over to the file structure tab. 

I ran the command below, so that I had the correct write permissions for copying across:

```bash
sudo chmod -R 777 /home/user/PiProject-homelab/mkdocs/mkdocs-data/docs
```
