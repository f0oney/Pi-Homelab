A client is essentially a individual tunnel that you can use to connect your device to the local network. It is heavily recommended to create separate clients for each device. This example will walk through creating one for my laptop.

### Client Process

To start creating one, simply run the command below:

```bash
pivpn -a
```

This will prompt to enter the Client IP from range. You can either enter one yourself, or press enter to let Pivpn pick one for you:

```bash
::: Chosen Client IP: random IP
```

It will then ask for the name of the client. You will receive confirmation that this has been created successfully. 

### Adding Tunnel to the Wireguard Mobile App

We can use command `pivpn -qr`, and enter the client name, to generate the QR of the client. This can be scanned from the Wireguard Phone App. 

To do this, open the Wireguard app and press the + symbol, selecting **Scan from QR code**. This should then add the tunnel to your app for use.

### Adding Tunnel to the Wireguard Desktop App

To add the tunnel to your Desktop app, we will need to physically save the `.conf` file of the client, and add to the application. These client `.conf` files are located in `/home/user/configs`.

To download this file onto our laptop, I am using application **MobaXTerm**, which will let me physically right-click the file within the file directory pane, and press **Download**:

![[Pasted image 20260819222725.png]]

Once downloaded, we can open Wireguard and navigate through the following:

1. Click **Add Tunnel**
2. Locate the saved `.conf file`, and double-click to open
3. You should then see the tunnel appear on your list. Press **Activate** to start up the VPN.
