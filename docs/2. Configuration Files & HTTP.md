To begin with the configuration of Nginx, we will need to understand it's file structure. From our docker compose file, volume `/etc/nginx/conf.d` will be pointing at our home user folder. This for me is `~/pihomelab/nginx`. The docker container has already created and setup the relevant config files, including sites-available folders and the nginx configuration file, which we won't see, but is contained in `/etc/nginx` of the docker container.

Any additional config files, mainly being our proxy server block file, will be added under our desired home folder as stated on the volume, and which our docker container will be actively checking and pulling.

For this setup, we will only need to worry about creating a .conf file, which will contain our server block proxy configuration. CD into your chosen area, and create the .conf file, choosing a name that suits it best for you. My file will be named `serverblock.conf`.

```bash
cd ~/pihomelab/nginx
sudo touch serverblock.conf
```

```bash
sudo nano serverblock.conf
```

##### Server Block Example
For a basic HTTP setup which will be used for our Pihole service, we can use the following template:

```
server {
	listen 80;
	server_name example.com www.example.com http://www.example.com; #Replace with your domain/IP           
	location / {
		proxy_pass http://pihole:80; #Backend server URL/port           
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;           
        proxy_set_header X-Forwarded-For 
        $proxy_add_x_forwarded_for;           
        proxy_set_header X-Forwarded-Proto $scheme;       
    }   
}
```

On the line `proxy_pass`, we will only need to call 'pihole' as the docker container, as opposed to our IP Address. Port 80 is then added, as this is the default port Pihole uses.

With the lines added to the file, we can save this and test the configuration for any syntax errors. As we will need to run the command inside of the docker container, `docker exec` is added:

```
docker exec nginx_proxy nginx -t
```

If all is good, we can then reload nginx to apply the changes:

```
docker exec nginx_proxy nginx -s reload
```
