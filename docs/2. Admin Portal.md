## Users Tab

The **users** tab will show us the currently active accounts, and the ability to remove, disable, or invite new users to the system.

## Diagnostics Tab

The diagnostics tab will display the following:

!\[\[Pasted image 20260818230212.png]]

Things to note:

1. The **Server Installed** field will display if and when the image is out of date, and needs updating
2. If **Internet Access** has an error, and cannot reach the Github page, then the DNS is not set correctly under the compose file
3. If the **Websocket** field has error'd, this will mean the Nginx proxy server block is configured incorrectly

These as of current, are running as expected with no errors.
