Once Portainer is up and running, we can load up the webpage using the domain setup on Nginx. This will bring up the setup page.

On the setup page, enter your username, and a password to set again the account. For the setup token, you can obtain this by running the docker logs command for the portainer container:

```bash
docker logs portainer
```

In the logs, it will show the setup token, which you can copy and paste into and accept.

The primary environment should already be setup. You can click on this under the 'Environments' tab. To confirm Swarm is running correctly, and that your node appears in the list, click on the 'Swarm' tab on the navigation menu under the environment, and choose 'Details'

Here, you should see two nodes, one being your primary manager, and the other being the one you joined the swarm with.
