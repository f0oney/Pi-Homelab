Portainer is a service used to manage our docker containers via a web interface. This gives us options for viewing images, creating new containers, shutting down current ones, and so on. 

However, if you have multiple servers, then it is harder to manage this. You can create separate environments for each server, but if you're wanting to share across the same docker network, then this won't be a viable solution.

--------------------------------------------------------------------------
### Docker Swarm

This is where using Docker Swarm comes in. A Docker Swarm network allows containers to communicate with each other across multiple hosts (servers, or nodes), as if they were all on the same server or local network.

As for my current setup, I have two servers: Proxmox and Raspberry Pi, both of which host docker containers. As I am wanting to setup a Docker network for my containers, I can create a new Swarm docker network, which Portainer can pickup and use.

You will need to decide which server you're using, which will be the 'manager' of the swarm network. In my case, I have picked my Raspberry Pi as the host, as this hosts my main docker containers such as Nginx.

### Creating the Swarm

Once decided, we first need to create the overlay network itself. We will need to give it a name, and if required, specify which network address we will be using:

```bash
# Initialize the swarm, making the current node manager
docker swarm init --advertise-addr eth0
```

This will output a join command which you can use later on another node. Example of one below:

```bash
# Output of command
docker swarm join --token SWMTKN-1-TOKEN [IP]:2377
```

### Creating the overlay network

Once swarm is active, and confirmed that the server chosen is set as the manager, we can then proceed on creating the Docker Network. This network will be used across all docker compose files, so that the containers are linked and can communicate with each other.

To do this, run the following command below to create the network:

```bash
# Creating a new external network for Portainer and all over containers to use
docker network create --driver overlay --attachable swarm_network

# Outputs token
```

Once created, we can use the following lines in Docker Compose files, to include this:

```bash
networks:
   - swarm_network
     

network:
   swarm_network:
      external: true
      driver: overlay
```

### Installing Portainer Stack

With both Swarm and the network setup, we can then proceed with installing the Portainer Stack. A stack allows us to install multiple docker containers as a single application. In this installation, it will install both the portainer container, as well as the agent.

Firstly, we can grab the stack .yml from Portainer themselves. Ensure this is done in your preferred location. For this example, it will be done under `~/Pi-homelab/docker-compose`

```bash
# Grabs the stack .yml
curl -L https://downloads.portainer.io/ce-lts/portainer-agent-stack.yml -o portainer-agent-stack.yml
```

#### Docker Compose File

We can then edit this .yml, and add the following below:

```bash
# edit the created yaml, to include the external network
version: '3.2'

services:
  agent:
    image: portainer/agent:lts
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - /var/lib/docker/volumes:/var/lib/docker/volumes
      - /:/host
    networks:
      - swarm_network
    dns:
      - ${UNBOUND_DOCKER_IP}
    deploy:
      mode: global
      placement:
        constraints: [node.platform.os == linux]

  portainer:
    image: portainer/portainer-ce:lts
    command: -H tcp://tasks.agent:9001 --tlsskipverify
    dns:
      - ${UNBOUND_DOCKER_IP}
    ports:
      - "9443:9443" # Default Interface Port
      - "9000:9000" # Default HTTPS Port
      - "8000:8000" # Default HTTP Port
    volumes:
      - portainer_data:/data
    networks:
      - swarm_network
    deploy:
      mode: replicated
      replicas: 1
      placement:
        constraints: [node.role == manager]

networks:
  swarm_network:
    external: true
    driver: overlay

volumes:
  portainer_data:
```

Once entered and saved, deploy the stack:

```bash
# Deploy the stack
docker stack deploy -c portainer-agent-stack.yml portainer
```

### Adding nodes

When the Portainer containers are active, we can request the join token from the manager node, and use the generated command on the node for it to join.

```bash
# Obtain the docker swarm join token for a new node
docker swarm join-token worker
```

```bash
# Run the generated command the above one had provided, on the other server
docker swarm join --token SWMTKN-1-TOKEN [IP]:[PORT]
```
