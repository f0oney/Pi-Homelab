# 1. Portainer SWARM Setup

Portainer is a service used to manage our Docker containers through a web interface. This gives us options for viewing images, creating new containers, shutting down current ones, and so on.

However, with multiple servers, this gets harder to manage. You can create separate environments for each server, but if you want them to share the same Docker network, this isn't a viable solution.

---

### Docker Swarm

This is where Docker Swarm comes in. A Docker Swarm network allows containers to communicate with each other across multiple hosts (servers, or nodes), as if they were all on the same server or local network.

My current setup has two servers, Proxmox and Raspberry Pi, both of which host Docker containers. To set up one Docker network for all my containers, I can create a swarm with an overlay network, which Portainer can pick up and use.

You will need to decide which server will be the 'manager' of the swarm. In my case, I have picked my Raspberry Pi, as it hosts my main Docker containers, such as Nginx.

### Creating the Swarm

Once decided, we first need to initialise the swarm on that server, which makes it the manager:

```bash
# Initialise the swarm, making the current node manager
docker swarm init --advertise-addr eth0
```

This outputs a join command, which you can use later on another node. Example below:

```bash
# Output of command
docker swarm join --token SWMTKN-1-TOKEN [IP]:2377
```

### Creating the overlay network

Once the swarm is active, and the chosen server is confirmed as the manager, we can create the Docker network. This network will be used across all Docker Compose files, so that the containers are linked and can communicate with each other.

To do this, run the following command:

```bash
# Creating a new external network for Portainer and all other containers to use
docker network create --driver overlay --attachable swarm_network
```

Once created, we can use the following lines in Docker Compose files to include it:

```yaml
services:
  myservice:
    networks:
      - swarm_network

networks:
  swarm_network:
    external: true
```

The network has already been created as an overlay, so `external: true` is all that's needed. A `driver` line isn't required for an external network.

### Installing Portainer Stack

With the swarm and network set up, we can install the Portainer stack. A stack installs multiple Docker containers as a single application. This installation includes both the Portainer container and the agent.

First, grab the stack .yml from Portainer. Make sure this is done in your preferred location. For this example, it will be done under `~/pihomelab/docker-compose`:

```bash
# Grabs the stack .yml
curl -L https://downloads.portainer.io/ce-lts/portainer-agent-stack.yml -o portainer-agent-stack.yml
```

#### Docker Compose File

Edit this .yml to match the following:

```yaml
# edit the downloaded yaml, to include the external network
version: '3.2'

services:
  agent:
    image: portainer/agent:lts
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - /var/lib/docker/volumes:/var/lib/docker/volumes
      - /:/host
    networks:
      - swarm_network
    dns:
      - ${UNBOUND_DOCKER_IP}
    deploy:
      mode: global
      placement:
        constraints: [node.platform.os == linux]

  portainer:
    image: portainer/portainer-ce:lts
    command: -H tcp://tasks.agent:9001 --tlsskipverify
    dns:
      - ${UNBOUND_DOCKER_IP}
    ports:
      - "9443:9443" # Web interface (HTTPS)
      - "9000:9000" # Web interface (HTTP)
      - "8000:8000" # Edge agent tunnel
    volumes:
      - portainer_data:/data
    networks:
      - swarm_network
    deploy:
      mode: replicated
      replicas: 1
      placement:
        constraints: [node.role == manager]

networks:
  swarm_network:
    external: true

volumes:
  portainer_data:
```

Once entered and saved, deploy the stack. `docker stack deploy` doesn't read `.env` files, so load the variables first, otherwise `UNBOUND_DOCKER_IP` will be empty:

```bash
# Load the .env variables, then deploy the stack
set -a; . ./.env; set +a
docker stack deploy -c portainer-agent-stack.yml portainer
```

### Adding nodes

When the Portainer containers are active, we can request the join token from the manager node, and run the generated command on the new node so it joins the swarm.

```bash
# Obtain the docker swarm join token for a new node
docker swarm join-token worker
```

```bash
# Run the command generated above on the other server
docker swarm join --token SWMTKN-1-TOKEN [IP]:[PORT]
```
