To install Pihole, we can use Docker Compose. This will allow us to use a `.yaml` file, which also contains the Unbound DNS container, that can work alongside Pihole.

-------------------------------------------------

### File Structures

As for the location of the `yaml` file, we will store this via `~/pihomelab/docker-compose`, which will be where we are storing the docker compose files for all Docker services.

The data files and configs will be stored under `~/pihomelab/pihole` (for Pihole) and `~/pihomelab/unbound` for unbound. We also have the `dnsmasq.d` sub folder, which will be in the same location. This can be specified in the `piholeunbound-compose.yaml` file itself.

##### .gitignore
Any data and config files we don't want to share with the GitHub repo, will be added to the `.gitignore` file. This will include:

- /pihole folder
- /dnsmasq.d

### Docker Compose File

The following config is to be entered within the `.yaml` file:

```bash
services:
  pihole:
    container_name: pihole
    image: pihole/pihole:latest
    ports:
      - "53:53/tcp"
      - "53:53/udp"
    environment:
      TZ: ${TZ}  # Replace with your timezone
      FTLCONF_webserver_api_password: ${PIHOLE_PASSWORD}  # Change this!
      DNSMASQ_LISTENING: "all"
      PIHOLE_DNS_1: "unbound#53"  # Point to unbound container
    volumes:
      - ${PIHOLE_VOLUME}:/etc/pihole
      - ${DNSMASQ_VOLUME}:/etc/dnsmasq.d
    restart: unless-stopped
    networks:
      dns_network:
    cap_add:
      - NET_ADMIN
      - NET_RAW
      - CAP_SYS_NICE
      - CAP_SYS_TIME
    security_opt:
      - seccomp:unconfined
    depends_on:
      - unbound
  unbound:
    container_name: unbound
    image: klutchell/unbound:latest
    volumes:
      - ${UNBOUND_VOLUME}:/etc/unbound/custom.conf.d
    restart: unless-stopped
    networks:
      dns_network:
networks:
  dns_network:
    external: true
    driver: bridge
```

`ports:` - Even though this is within our Docker Network, we still need to specify port 53 in this compose file, as this is the default port used for DNS. Without this, Pihole simply won't function as port 53 is not defined.

`networks:` - Our dns_network is specified for connection.

##### .env File

**Note**: For the password in this configuration, it is finding and using a created variable. We can just set a plain text password, but we can use this instead if sharing this config on GitHub, so it is hidden. To do this, create a new file in the same location named `.env`, and enter the following in it's file:

```bash
PIHOLE_PASSWORD=INSERT_HERE
```

`INSERT_HERE` can be replaced with the chosen password. `.env` is used, as GitHub is setup to ignore and not pull any `.env` files, as specified in it's `.gitignore` file, under `~/pihomelab`.

### Deploying the compose file

Once this file(s) have been created, and config lines used above, we can then initiate it's installation via the following command:

```bash
sudo docker compose -f piholeunbound-compose.yaml up -d
```

Wait for the installation to finalise. Once finished, we can check that both the Unbound and Pihole containers are running via `sudo docker ps`.

## Updating Pihole/Unbound

As for all docker containers, please ensure that the containers are updated with the latest image!!

We can check if this is out of date, via the portal itself at the bottom of the page. This will note as **Update Available**. 

Run the following command to pull the latest image, and then stopping and deleting the current containers, before installing again via the compose file:

```bash
docker pull pihole/pihole:latest
docker pull klutchell/unbound:latest
```
