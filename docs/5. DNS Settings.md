For domains using Nginx, to redirect to specified IPs + Ports, we need to add each local domain entry to point to the Raspberry Pi IP, where Nginx is hosted.

This is so that once the request is received to connect onto the local domain, it is forwarded straight to Nginx, that then deals with the reverse proxy side.

### How it works

For example, Proxmox is currently hosted on a different server using IP example 192.168.0.56, and port 8005. The reverse proxy is setup on Nginx, hosted on `192.168.0.123`, with code blocks setup in file `/etc/nginx/sites-available/your.sites` (refer to the Proxmox note under Nginx RP Blocks folder). The IP that proxmox.user.local points to will therefore be `192.168.0.123`, as we want to forward it to Nginx to deal with:

### Simple Local Domain Setup via Pihole

Other domains that do not need to be managed by Nginx, can point directly to their designated IPs. To find the configuration for this, and add new domains, we can follow through these simple steps:

1. In the Pihole admin portal, navigate to Settings > Local DNS Records
2. In the Local DNS records pane, within the Domain table, enter the full domain name, alongside it's associated IP
3. Once entered, click the green + symbol
