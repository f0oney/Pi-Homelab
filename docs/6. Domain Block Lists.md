One of the main features of Pihole, is it's ability to block numerous queries and domains on a network level, meaning any device connected to the network it's running on, will have these domains automatically blocked. This is particularly useful for blocking ADs!

With Pihole up and running, we can add a block list via the Web Interface, which is essentially a simple list full of domains we want to block.

### Obtaining a blocklist URL link

To find a particular block list to add to our Pihole, we can search the web for various lists created by the community. For me, I have used **Hagezi's Ultimate** blocklist, found on his GitHub page. You can find this on the following URL: https://github.com/hagezi/dns-blocklists

To obtain the blocklist link, scroll down the README, and save the 'Adblock' link (which states it can be used for Pihole) under the intensity level you'd like to choose:

!\[\[Pasted image 20260817214434.png]]

This method will be similar on any other GitHub page, or site you use, by copying the link to the list.

**PLEASE NOTE** - The blocklist I am currently using, is considered aggressive, and therefore may break certain websites. I therefore tend to manually permit certain domains if I find them to completely break sites that I want to visit, which I will show how to do further down this section.

### Adding to Pihole

Once you've obtained the link to the blocklist you'd like to add, we can follow the steps below to add this to Pihole:

1. Login to Pihole, using the login details setup in the installation process.
2. Navigate to Lists under Group Management
3. Here, you will see the Add a new subscribed list panel, and the Subscribed lists panel. Currently, your subscribed lists should be empty. This will be where your active lists will sit. To add a new list, we will need to paste the saved blocklist URL we obtained earlier into the Address field, and add a chosen comment:  !\[\[Pasted image 20260817214929.png]]
4. Press **Add blocklist**
5. This will then appear under your **Subscribed lists**, with status **Enabled**:

### Allowing certain domains

As mentioned previously, if you have an aggressive blocklist, that may have broken a particular website you're using, it is handy to be able to allow that particular domain through as an exception.  To do this, we first will need to identify which domain is being blocked. We can find this by using the **Query Log**.

Load or perform the certain action that is not working correctly, e.g. Facebook comments, and look for the domain that is being blocked during that moment. For example, as soon as I attempt to open Facebook comments, I can find the following being blocked:

On these entries, you can add a comment to note the reason for allowing it, so you can easily keep track. I would then recommend updating the Gravity list, to apply the changes...

### Updating Gravity List

When you have added a new blocklist, it is always recommended to immediately update the gravity list via Pihole. The gravity list is the main compiled database of blocked domains, where Pihole downloads the addresses from your subscribed lists, combines them, and removes any duplicates that may crop up when you have multiple lists. Once updated, all your lists should be active on Pihole.

To do this, click through the following settings:

1. In the Pihole interface, click on **Tools** > **Update Gravity**
2. Click **Update**
3. You should see the following command portal appear, showing you if the update was successful. Any errors will also appear if it has failed to update all:
