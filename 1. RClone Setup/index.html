    1. RClone Setup

    With the current setup (pre-NAS Server), I have been using RClone, which can be used to backup chosen folders of data from the Raspberry Pi, and upload to a Cloud Service. For my chosen Cloud Service, I have decided to use Proton Drive.

    Note: This was done as the root user, using command sudo su

    To start, we can first install RClone via the following command:

    sudo -v ; curl https://rclone.org/install.sh | sudo bash

    Once installed, we will need to proceed on setting up the config. This will trigger prompts for setting up our backups to the Cloud Service:

    rclone config

    Proceed with the following options:

    1. Enter n to start a new remote.
    2. This will prompt for a name. I have entered 'ProtonDrive'.
    3. We will then need to pick our Cloud Service. Choose 43 for Proton Drive.
    4. For this service, enter the email address used for the Cloud Service Login.
    5. Choose the option for entering your password to the Cloud Service Account.
    6. Enter the 2FA code tied to your Cloud Service Account (6-digit Code).
    7. Do not enter a secret key, or editing the advanced config when prompted.

    Once the setup is complete, run the command below to check that RClone is picking up the Cloud Service folders present on the account:

    rclone lsd ProtonDrive:

    For example, in my Proton Drive, I have folder 'Raspberry Pi Backups' present, which this command outputs.

    We can now proceed on creating the backup script. I have navigated to /etc/backups, where this script will sit. The following is set inside of file backupscr.sh:

    #!/bin/bash

# ==== Configuration ====
REMOTE_NAME="ProtonDrive"
DESTINATION_BASE="Raspberry Pi Backups"
SOURCES=( "/home/user" "/etc/" ) #The two folders we want to back up
TIMESTAMP=$(date +"%Y-%m-%d_%H-%M-%S")
DESTINATION="$REMOTE_NAME:$DESTINATION_BASE/$TIMESTAMP"
FILELIST="/tmp/rclone_files.txt"
# =======================

# Clear previous file list
> "$FILELIST"

echo "Starting backup to: $DESTINATION"

# Collect all files from each source folder
for SRC in "${SOURCES[@]}"; do
    if [ -d "$SRC" ]; then
        find "$SRC" -type f >> "$FILELIST"
        echo "Added files from: $SRC"
    else
        echo "Warning: $SRC is not a valid folder. Skipping."
    fi
done

# Run rclone to copy the files while preserving full paths
rclone copy / "$DESTINATION" \
    --files-from "$FILELIST" \
    --create-empty-src-dirs \
    --copy-links \
    --progress

echo "Backup finished!"

    This backs up both the /etc/ folder, and the /home/user/ folder. To make this script executable, run the following:

    sudo chmod +x backupscr.sh

    You can then run this manually via the following command:

    ./your_script_name.sh
