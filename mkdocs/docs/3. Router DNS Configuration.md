With Pihole + Unbound now setup, we lastly need to make sure that all devices connected to the local network, is using this configuration as it's DNS. Currently, all devices will still use the default router's DNS settings, so therefore, Pihole with Unbound is completely bypassed. To change this, we will need to go onto the router's portal and amend it.

### Router Steps

For my setup, I have obtained a third party router, specifically model **RT-AX52 Pro by ASUS**. I had to purchase one of these, to allow me to add custom configurations for DNS, as well as other features and settings I would not get with my default router provided by my ISP, due to custom configurations being locked down.

1. Firstly, login to your router via it's local IP on the browser, usually `192.168.0.1`. For ASUS, it will prompt for my username and password which I set in it's setup.
2. Once logged in, navigate to **LAN** under **Advanced Settings**, and then click on the **DHCP Server** Tab.
3. Look for fields **DNS Server 1** and **DNS Server 2**, under **DNS and WINS Server Setting**.
4. On both these fields, enter the Raspberry Pi's IP Address, where Pihole and Unbound is hosted on. Again, this will usually be something like `192.168.0.x`. 

   ![[Pasted image 20260817213054.png]]

   - We want both servers set to this, so that it does not have any chance in using another DNS Server.

5. Press Apply. This will reboot the router, and apply the changes.

The networks DNS should now use the Raspberry Pi's IP, which both Pihole and Unbound are hosted on, and direct all queries to this going forward. Any device on the network will therefore use this going forward.
