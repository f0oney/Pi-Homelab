I've set crontab to run every Saturday, at 3AM, using the backup script located in `/home/fooney/raspberrypi-homelab/`. Done this by:

```bash
Crontab - e
```

Press option 1

In the file, we've added the following line:

```bash
0 3 * * 6 /home/user/homelab/backupscr.sh
```

These parameters state it will run every week, on a Saturday. We can use the following website that will help show which parameters we will need to use:

[https://crontab.guru/#0_3_*_*_6](https://crontab.guru/#0_3_*_*_6)

The following explains each part of the syntax:

- 1: Minute (between 0 and 59)
- 2: Hour (between 0 and 23)
- 3: Day (between 1 and 31)
- 4: Month (between 1 and 12)
- 5: Day of week (between 0 and 7, starting on Sunday)
