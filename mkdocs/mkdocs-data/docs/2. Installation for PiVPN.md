Pivpn is a easy-to-use script we can run, that will allow us to install our chosen VPN Protocols. In this case, we will be installing Wireguard via this script. This Wireguard VPN will allow us to access the services hosted on our Pi, as well as the Proxmox server, from outside of the local network. This will connect us to the network, as if we're a device within the network.

**PLEASE NOTE:** This guide assumes you have already setup Pihole + Unbound. If not, please refer to [1. Installation].

### Installation Command

To get started, we can simply run the installation command here:

```bash
curl -L https://install.pivpn.io | bash
```

- If `sudo apt update` has not been ran beforehand, this will automatically run, and update any packages available.

### GUI Steps

This will initiate a GUI Installation. Follow through the prompts as below:

1. Press OK

2.  Press OK - We already have static IP address `192.164.x.x` set.

3. Select Yes, as this is still a good idea so that it stops private data from leaking if it uses ipv6 in the future.

4. Press space on `eth0`, which is the Ethernet connection used for the Pi. If using Wi-Fi, select WAN, and press OK.

5. Press Yes, as DCHP Reservation is being used for IP `192.168.x.x`.

6. Press OK, and select `user` or the main local account you're using for the Pi.

7. Select Wireguard using the spacebar, and press OK.

8. Stick with port `51820`, and press Ok (We will ensure this is port forwarded on the Router config later on) then Confirm.

9. Select `PiVPN-is-local-DNS` by using the spacebar, and pressing OK. As noted, as we're using unbound, we should select this option.

10. Choose DNS Entry.

11.  Enter the domain name that we set earlier under [1. Router DDNS & Port Forwarding]. This will be `x.asuscomm.com`.

12.  We will then have confirmation that the server keys will be generated. Press OK.

13. This will recommend enabling `unattended-upgrades`. We can confirm, and press Yes, as this is an important feature to enable for automatic security package updates.

14. This will then confirm the installation has complete. Press OK, and press Yes to confirm reboot.

We can then move on to creating our client.
