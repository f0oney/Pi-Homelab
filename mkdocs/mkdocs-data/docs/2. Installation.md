Pivpn is a easy-to-use script we can run, that will allow us to install our chosen VPN Protocols. In this case, we will be installing Wireguard via this script. This Wireguard VPN will allow us to access the services hosted on our Pi, as well as the Proxmox server, from outside of the local network. This will connect us to the network, as if we're a device within the network.

###### **PLEASE NOTE:** This guide assumes you have already setup Pihole + Unbound. If not, please refer to [[Raspberry Pi/Pihole & Unbound/1. Installation|1. Installation]].

To get started, we can simply run the installation command here:

```bash
curl -L https://install.pivpn.io | bash
```

- If `sudo apt update` has not been ran beforehand, this will automatically run, and update any packages available.
