# 1. Router DDNS & Port Forwarding

Before we get started, we need to setup our router for port forwarding on port 51820, and enabling DDNS.

- A Dynamic DNS service is used to automatically update the IP Address if and when it changes. This is useful to use for our VPN, as if the Router reboots, we won't need to manually update the public IP again for our VPN to use.
- Port forwarding allow us to open port 51820, so that we can connect through to the local network via this.

These steps will go through the ASUS Router settings.

### Port Forward

Log into your router dashboard, usually being `192.168.x.1`.

On the dashboard, under Advanced Settings, click **WAN** > **Virtual Server / Port Forwarding**. 

The page will show a table of where your port forwarded ports will show. Press **Add Profile**, and fill in the following information:

![[Pasted image 20260820180307.png]]

Service Name - Name of your choosing
Protocol - BOTH
External Port - 51820
Internal IP Address - localserver IP of where your PiVPN service will be hosted on
Press OK to confirm settings.

### DDNS Service

On the same router dashboard, navigate to **WAN** > **DDNS**. On this page, we can fill in the following details:

- DDNS - Toggle ON
- Server - WWW.ASUS.COM
- Host name - Name of your choosing (.asuscomm.com)
- HTTPS/SSL Certificate - Auto

Then press **Apply**.

We can check if this has applied and registered successfully, checking under Network Map > Internet Status > DDNS name
