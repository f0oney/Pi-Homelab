The Portainer Agent will allow us to have our Raspberry Pi Docker Containers manageable via the Portainer web portal, hosted on the **Debian VM** on our **Proxmox Server.**

To set up our agent, we first need to make sure the Portainer Server is setup, which you can refer to the guide [Proxmox/Debian VM (Docker Server)/Portainer/1. Installation]. Once this is confirmed all up and running on it's host server, we can begin. 

----------------------------------------------------------

### Setup via Portainer Server

Firstly, login to the Portainer Web Portal via your chosen IP/local domain. 

Once in, navigate through to **Environment-related** > **Environments** > Click **Add Environment**. We can then walk through the following steps:

1. Select **Docker Standalone**, and press **Start Wizard**
2. Ensure **Edge Agent Standalone** is selected
3. Enter the following in the fields:
	1. Name: Pi-Agent
	2. Portainer API server URL: localserver domain [Auto-Fills]
4. Once all entered, press **Create**
5. This will populate new fields, as well as our Join token, that we will need to use to connect the Agent. 
6. Enter **EDGE=1** in the **Environment Variables** field and copy the generated command:

```bash
docker run -d \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v /var/lib/docker/volumes:/var/lib/docker/volumes \
  -v /:/host \
  -v portainer_agent_data:/data \
  --restart always \
  -e EDGE=1 \
  -e EDGE_ID=58634afe-3c32-4113-8322-6ed18ef29c60 \
  -e EDGE_KEY=aHR0cHM6Ly8xOTIuMTY4LjUwLjE3MTo5NDQzfDE5Mi4xNjguNTAuMTcxOjgwMDB8ekJlVGt3dW1qaVBHb2FnUVY0WFUwd1ZCU2M1UjEzNUw5T0tZTWphSmUwTT18Ng \
  -e EDGE_INSECURE_POLL=1 \
  -e EDGE=1 \
  --name portainer_edge_agent \
  portainer/agent:2.39.5  
```

### Setup via Pi Device

SSH onto the Raspberry Pi, and paste the command in to run. The Edge Key will already contain the generated key on Portainer, so no amendments are needed.

Confirm the command has ran, and the docker container for the agent has installed successfully via `docker ps`. This should show a new container on the Pi named portainer/agent.

Once the docker container is running, go back onto the Portainer Portal, and click on the Home tab. We can then confirm whether this is showing as running, and pulling our containers correctly:
