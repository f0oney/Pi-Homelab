Inside of `/home/user/PiProject` (your named repo folder), we want to add in the files we would like to share to our GitHub repository. We need to be careful with how we do this however, as we do not want to share sensitive information such as API keys. 

-----------------------------------------------------------

### Seperating shared data and non-shared data with Github

For my setup, I have therefore created an additional folder for what files I would like to keep off Github, using **ProjectPi** as the example:

`/home/user/PiProject/` 
- Contains `/pihole-unbound`, only hosting the unbound files and the `compose.yaml`

`/home/user/PiProject-Data/`
- Contains data relating to the services, that I do not want hosted on GitHub. This includes the main pihole configuration files, dnsmasq.d, and other sensitive service data

The Pihole configuration folder is an example of one that we do not want to share on Github, as this contains site history, queries, client activity, and Gravity.
