Nginx is a reverse proxy, which can be used to redirect IP Addresses with different ports, to different local domains setup in Pihole.

-----------------------------------------------------

### How it works

In this case, we have our Raspberry Pi IP `192.168.0.x`. As we have multiple services running, with different web interfaces, we won't be able to setup multiple local domains normally, as they all use the same IP Address. All the services running on docker containers however use different ports. This is where Nginx comes in.

The following can be setup:
	Pihole for example can use port 7000, whereas Vaultwarden uses port 6000. We can get Nginx to assign local domain `pihole.user.local` to `192.168.0.x:7000`, and local domain `vault.user.local` to `192.168.1.x:6000`. 

This will use HTTP, but we can also configure it to use HTTPS, using self-signed certificates. These will all be setup in a configuration file, which I will guide through in this Nginx section.

### Package Install Command

First, we will need to install Nginx on our Pi. To do this, we can run the following command:

```bash
sudo apt install nginx -y
```

In this case, I have decided to not install nginx in a docker container, so that it is easier for setting up, and easier to communicate with the services.
