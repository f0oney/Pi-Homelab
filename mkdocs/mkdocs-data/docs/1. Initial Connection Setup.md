For displaying and presenting my configs, documentation, and GitHub Pages, setting up GitHub on the Raspberry Pi is key. This is how I am currently hosting my documentation, as well as my configuration on the repo. 

--------------------------------------------------------------

### Deployment of the GitHub Package

Ensure first that github is installed on the device:

```bash
sudo apt install git -y
```

We can then run through the following commands, to set our global username and email address. Enter your personal username and email address in place of "user" and "user@mail.com":

```bash
git config --global user.name "user"
git config --global user.email "user@mail.com"
```

To view what has been set:

```bash
git config --list
```

### SSH Key

To avoid entering your username and password every time you interact with remote repositories, we can setup an SSH key, so that this automatically authenticates with the device (Raspberry Pi).

To do this, we can generate the key using the following command:

```bash
ssh-keygen -t ed25519 -C "user@mail.com"
```
- When prompted, you can press enter for the default path
- It will also prompt you for a passphrase. Press enter to skip if not needed

SSH Key under `/home/user/.ssh/id_ed25519.pub`
Pass Phrase is: Enter Pass Phrase

We can then copy the SSH key to our clipboard, so we can add it to github. We can use a tool called xclip to do this:

```bash
sudo apt install xclip -y
xclip -sel clip < ~/.ssh/id_ed25519.pub
```

We can then paste this into the new SSH Key entry that we will add on GitHub:

1. Login to Github
2. Click on your Profile Picture and select Settings
3. Click on the SSH and GPG keys tab
4. Click New SSH key
5. Enter the name of the key, which will be Raspberry Pi 4 Git Key, and the copied SSH key
6. Press Add SSH Key

We can test the connection via the following command:

```bash
ssh -T git@github.com
```

It will appear with a warning to say it can't be established, but press yes to trust the key. It will then ask for your pass phrase, and confirm connection.
